# Aventura interactiva "Ámsterdam nocturna"

Este repositorio contiene una aventura narrativa para jugarse en la terminal de macOS (o cualquier sistema con Python 3 instalado).
Explorarás la ciudad de Ámsterdam desde una perspectiva adulta: decisiones sobre arte, gastronomía, redes profesionales y momentos íntimos
que dan forma a una noche intensa sin recurrir a elementos de terror.

## Cómo jugar

1. Abre la terminal.
2. Navega hasta la carpeta de este proyecto.
3. Ejecuta:

   ```bash
   python aventura.py
   ```

La historia propone un recorrido ramificado con consecuencias que afectan tu energía, tus contactos y los recuerdos que registras en
un cuaderno imaginario. Cuando decidas retirarte (o te quedes sin energía), obtendrás un resumen personalizado de tu travesía.
